Dokumentation

Installation

  • Projektordner in Visual Studio Code öffnen.
  • Für lokale Nutzung die Datei index.html öffnen.
  • Für beste API-Funktion: mit einem lokalen Server starten (z.B. VS Code Live Server).

Verwendete APIs

  • Le Système Solaire API: Planetendaten (Radius, Umlaufzeit, Distanz).
  • NASA APOD: Bild des Tages auf der Seite „Geschichte“.
  • NASA Images API: Bilder für Timeline-Karten.

Navigation

  • Sonnensystem: Übersicht mit Sonne und Planeten im Orbit-Layout.
  • Planeten: Detailseite eines ausgewählten Himmelskörpers.
  • Geschichte: Scrollbarer Zeitstrahl mit Suche.
